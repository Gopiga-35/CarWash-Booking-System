# Car Wash Booking System

A **Java Servlet-based Car Wash Booking System** with database integration using **Oracle/MySQL**.  
This project allows administrators to manage car wash bookings and provides case-insensitive vehicle number search with proper date handling.

---

## Features

- Add, view, and manage car wash bookings.
- Case-insensitive search for vehicle numbers.
- Prevents duplicate bookings for the same vehicle and date.
- JSP-based user interface for booking display and management.
- Administrator-friendly interface for managing bookings.

---

## Technologies Used

- **Java Servlets & JSP**
- **HTML / CSS**
- **Oracle  Database**
- **JDBC** for database connectivity
- **Eclipse IDE** for development
